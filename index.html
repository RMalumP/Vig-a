Al guardar, la versión actual pasa a ser la nueva referencia, sin avisar.

Vigía

Escribe una dirección, elige cada cuánto mirarla y deja esta pestaña abierta. Si la página cambia, te avisa con una notificación flotante.

Opciones avanzadas

Comparar todo el HTML avisa hasta de cambios invisibles (anuncios, tokens), así que suele dar falsos avisos. Un selector CSS limita la vigilancia a una zona concreta, como un precio o una lista.

La ventana flotante se queda encima de las demás pestañas y programas, y muestra ahí los avisos.

Historial

    Si algo no funciona

    Muchas webs no dejan que otra página lea su contenido (bloqueo CORS). En modo automático, Vigía prueba primero el acceso directo y después varios proxies públicos. Si ninguno responde, esa web no se puede vigilar desde el navegador.

    Chromium ralentiza los temporizadores de las pestañas en segundo plano, a veces hasta una comprobación por minuto. Para intervalos muy cortos, deja esta pestaña visible o en una ventana aparte.

    Las notificaciones del sistema funcionan en GitHub Pages (https) y en localhost. Abriendo el archivo directamente (file://) puede que Chromium no las permita; la notificación flotante funciona siempre.
