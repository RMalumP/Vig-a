Conexión con GitHub

Crea un token fine-grained en GitHub (Settings → Developer settings → Personal access tokens), limitado solo a este repositorio y con permiso Contents: Read and write. Se guarda únicamente en este navegador, nunca dentro del archivo.

Cómo probarlo

  1. Sube index.html y prueba.html al repositorio y activa GitHub Pages (Settings → Pages).
  2. Abre …/index.html y vigila …/prueba.html cada 1 minuto.
  3. En esta página, rellena la conexión con GitHub y pulsa «Cambiar contenido». Se hará un commit.
  4. GitHub tarda entre 30 segundos y un par de minutos en publicar la nueva versión. Después, Vigía mostrará el aviso.
  1. Pon index.html y prueba.html en la misma carpeta y ejecuta ahí python -m http.server 8000.
  2. Abre http://localhost:8000/index.html y vigila http://localhost:8000/prueba.html cada 30 segundos.
  3. Abre esta página desde http://localhost:8000/prueba.html y pulsa «Cambiar contenido». La primera vez elige el archivo prueba.html y permite editarlo.
